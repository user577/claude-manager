Claude Manager + Ollama

Route Claude Code to local LLMs on your RTX 3090 — save API credits, keep full agentic workflow.

↓ How It Works

Since Ollama v0.14 (Jan 2026), Ollama natively speaks the Anthropic Messages API. Claude Code doesn't know it's talking to a local model — it just sees a different API endpoint.

Claude Manager sets two environment variables before launching each instance:

ANTHROPIC_BASE_URL=http://localhost:11434
ANTHROPIC_API_KEY=ollama

That's it. No proxy servers, no shims, no separate tools.

1 Install Ollama

Open a terminal and run:

winget install Ollama.Ollama

Or download from ollama.com/download.

After install, Ollama runs as a background service automatically. Verify with:

ollama --version
# ollama version is 0.14.x

2 Pull a Model

Choose a model that fits your 24GB VRAM. Here are the best options for coding:

ModelVRAMSpeedStrength
qwen2.5-coder:32b Best ~20 GB ~15 tok/s 92.7% HumanEval — top coding model
qwen3.5:27b Balanced ~16 GB ~22 tok/s 72.4% SWE-bench — good general reasoning
qwen3.5:35b-a3b Fast ~12 GB ~112 tok/s MoE — fast agentic work, only 3B active

Pull your chosen model (this downloads 15–20 GB once):

# Recommended: best coding quality on RTX 3090
ollama pull qwen2.5-coder:32b

# Optional: also grab a fast one for simple tasks
ollama pull qwen3.5:35b-a3b

Verify your models are available:

ollama list
# NAME                    ID           SIZE     MODIFIED
# qwen2.5-coder:32b      abc123...    20 GB    2 minutes ago
# qwen3.5:35b-a3b        def456...    12 GB    1 minute ago
Tip: You can pull additional models anytime. Claude Manager will discover them automatically when you click Refresh or re-open the local model dropdown.

3 Check the Status Dot

Open Claude Manager. Look at the toolbar — you'll see a colored dot to the left of the Pin button:

Green — Ollama running, ready to go
|
Red — Ollama not running
|
Gray — Checking...

Click the dot to see full details: version, available models, and install instructions if Ollama isn't found.

The dot auto-refreshes every 30 seconds. If it's red, start Ollama with:

ollama serve
Tip: On Windows, Ollama typically auto-starts as a background service after installation. If the dot is green, you're good — no need to run ollama serve manually.

4 Switch to Local Backend

On the Launch tab, find the new Backend dropdown (between Mode and Session):

Mode: Auto (full auto, confirm risky)
Backend: Local (Ollama) ▾
Local model: qwen2.5-coder:32b ▾ Refresh
Session: New session
  1. Set Backend to Local (Ollama)
  2. The Model row switches to Local model — pick from your pulled models
  3. If the dropdown is empty, click Refresh to re-query ollama list
  4. Select repos, set instance count, click Launch Claude

Each launched terminal window will run:

set ANTHROPIC_BASE_URL=http://localhost:11434 && set ANTHROPIC_API_KEY=ollama && claude --model qwen2.5-coder:32b

Switch back to Cloud anytime — the normal Sonnet/Opus/Haiku dropdown reappears.

? FAQ

How much VRAM does qwen2.5-coder:32b actually use?
About 20 GB at Q4_K_M quantization. Your RTX 3090 has 24 GB, leaving headroom for context. Ollama handles quantization and memory management automatically.
Can I run Cloud and Local instances at the same time?
Yes. Each terminal gets its own environment. Launch 2 instances with Cloud, then switch to Local and launch 2 more — they'll coexist. The env vars are per-process, not global.
What if Ollama isn't running when I launch?
Claude Code will fail to connect and show an error in the terminal. Start Ollama first (ollama serve) and check that the status dot is green before launching.
Will the local model have tool use / agentic capabilities?
Yes — Claude Code's agentic loop (file editing, bash, etc.) works the same way. The model quality determines how well it uses those tools. Qwen 2.5 Coder 32B handles tool use well.
How do I update a model?
Run ollama pull qwen2.5-coder:32b again — it'll download only the diff. Click Refresh in Claude Manager to pick up changes.
Can I use a custom / fine-tuned model?
Yes. Create a Modelfile, run ollama create mymodel -f Modelfile, and it will appear in the local model dropdown.
What's the API key "ollama" about?
Ollama doesn't require authentication, but Claude Code requires a non-empty ANTHROPIC_API_KEY. The string ollama is a dummy value — any non-empty string works.
